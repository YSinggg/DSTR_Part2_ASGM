# APU DSTR Assignment - Smart Campus Parcel System

Data Structures and Algorithms Assignment (Part 2).

### How to compile and run
Compile main.cpp using g++:
```
g++ -std=c++11 main.cpp -o ParcelSystem
./ParcelSystem
```
(Only compile main.cpp because all the tasks and data structures are in .hpp files)

### Features & Structures used
- Task 1: Parcel Intake & Sorting using Queue (FIFO linked list)
- Task 2: Service Request Management using Priority Queue (linked list sorted by priority)
- Task 3: Counter & Delivery Allocation using Circular Queue (fixed array with modulo wrap)
- Task 4: Parcel Activity History & Undo using Stack (LIFO linked list)

### Testing
When starting the program, enter 1 to load the sample data so you can test all the menus immediately.
